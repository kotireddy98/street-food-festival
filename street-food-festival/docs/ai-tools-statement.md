# Tools and AI use statement

MongoDB Atlas and its embedded MongoDB shell were used to create the database, collections, validation rules, indexes, and run CRUD and aggregation queries. The project scripts and report structure were prepared with AI assistance for learning and drafting. The student reviewed, ran, tested, and should be prepared to explain and modify every query; all screenshots, execution statistics, and observed business results must come from the student's own Atlas cluster. Synthetic order data was generated by the provided JavaScript loop.
